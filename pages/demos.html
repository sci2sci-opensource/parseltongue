Demos

Worked examples showing Parseltongue in action. Each demo is a self-contained project.

pgmd AI2AI Investment Memo

Three notebook patterns — standalone, explicit, implicit — analyzing a Series A investment memo. Shows facts with verified quotes, cross-document derivation, and taint tracking.

py Apple Arithmetic

Peano arithmetic from observational field notes. Builds successor notation, axioms, and derives from scratch using the Python API. Every symbol grounded in counting observations.

pltg Apple Arithmetic (.pltg)

Same orchard arithmetic, but loaded entirely through .pltg files with an empty environment. Proves the loader bootstraps Peano notation, axioms, imports, and derives from scratch.

pltg Apple Splats

Variadic splat patterns (?...) for operations like (sum-all a b c d). No more nested binary ops.

py Biomarker Evidence Conflict

Two papers on fecal calprotectin — one supports diagnostic value, the other challenges specificity. The system ingests both, derives contradictory conclusions, and flags the conflict.

py Code Implementation Checks

Facts extracted from a Python authentication module. Catches genuine code properties and fabricated claims about behavior that doesn't exist in the source.

pltg Biopharma Data Governance

Three-layer governance: technical catalog, legal contracts, business catalog. Cross-layer consistency checking with policy axioms, compliance predicates, and variadic reductions. The reference architecture for complex analyses.

pltg Deferred Directives

run-on-entry blocks that only fire when a file is the entry point. A library's deferred block is skipped on import, but executes when loaded directly.

py Documentation Validation

A library README with internally inconsistent claims. Config table says max_sessions=10 but no code backs it up; security section makes unverifiable audit claims; session management contradicts itself.

pltg Entry Mocks

Self-contained unit tests with let + mocks. Forward-declared primitives are rebound to mock values via run-on-entry, turning formal expressions into computable self-tests.

py System Extensibility

Custom effects passed at construction time. The DSL calls (load-data "name" "path") as a directive, hitting a user-defined side effect.

py Revenue Reports

Company performance analysis from multiple documents. System grows as evidence is ingested, with quote verification, fabrication propagation, cross-document inference, and manual override.

py Self-Healing Probes

Entire flow written in parseltongue DSL. Python only registers primitive effects and feeds the script. Effects as an instruction set: load-data, probes, and recovery.

py Spec Cross-Validation

API spec says 30-minute tokens, max 3 sessions, no MD5. Implementation has 1-hour expiry, 5 sessions, and uses MD5. Every divergence is caught.
